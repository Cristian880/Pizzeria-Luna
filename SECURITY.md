# Política de Seguridad

## Versiones soportadas

Este es un proyecto de aprendizaje en desarrollo activo. Actualmente solo la rama `main`
recibe actualizaciones de seguridad.

| Rama    | Soportada |
| ------- | --------- |
| main    | ✅        |
| develop | ⚠️ (en desarrollo, puede ser inestable) |

## Reportar una vulnerabilidad

Si encuentras una vulnerabilidad de seguridad en este proyecto, por favor **no la reportes
como un Issue público**. En su lugar:

1. Ve a la pestaña **Security** del repositorio.
2. Haz clic en **"Report a vulnerability"** para abrir un aviso de seguridad privado.
3. Describe el problema con el mayor detalle posible (pasos para reproducirlo, impacto
   potencial, versión afectada).

Como este es un proyecto personal de aprendizaje, no hay un SLA formal de respuesta, pero
cualquier reporte será revisado y atendido lo antes posible.

## Alcance

Este proyecto maneja datos simulados de usuarios y pagos de prueba (Stripe en modo sandbox).
No se procesan tarjetas de crédito reales ni datos personales reales de producción.
